# Aturan Nama File Laporan Praktikum

## Format Nama File

Setiap file laporan praktikum disimpan dalam format PDF dengan pola nama berikut:

```text
NIU_Nama Lengkap_PPG_Pertemuan X.pdf
```

Contoh untuk laporan Pertemuan 1:

```text
535493_Hafidz Rizqullah Prasetya_PPG_Pertemuan 1.pdf
```

## Data Praktikan

- Mata Kuliah: Praktikum Pengembangan Game (PPG)
- Nama: Hafidz Rizqullah Prasetya
- NIU: 535493 (NIM: 24/535493/SV/24243)
- Kelas: PL5A1

## Ketentuan Penamaan

1. Gunakan ekstensi `.pdf`.
2. Awali dengan NIU (`535493`).
3. Cantumkan nama lengkap.
4. Cantumkan kode mata kuliah `PPG`.
5. Cantumkan nomor pertemuan (`Pertemuan X`).
6. Untuk versi file sistem (tanpa spasi, aman untuk Git/URL), gunakan varian underscore:

```text
535493_Hafidz-Rizqullah-Prasetya_PPG_Pertemuan-1.pdf
```
