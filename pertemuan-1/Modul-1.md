## Intro to Version Control

**Industry Standard:** (Menunjukkan bahwa Git/GitHub adalah standar di industri).

**Alternatives:** manual approach.

### Istilah Dasar Penting Dalam Version Control
1. **Local**: Yang ada dalam perangkat pengguna.
2. **Remote**: Yang ada dalam cloud/hosting di mana repository ditempatkan dan dapat diakses oleh banyak orang.
3. **Commit History**: Catatan perubahan yang sudah dilakukan dan dikunci pada repository.
4. **Pull**: Mengambil data dan segala perubahan versi dalam suatu repository.
5. **Add**: Menambahkan file yang harus dilacak perubahannya.
6. **Commit**: Mengunci perubahan terbaru yang dilakukan pada file terlacak di local repository dan menyimpannya pada local commit history.
7. **Push**: Mengirim commit yang isinya perubahan file yang dilacak dan local commit history, dan melakukan penambahan dan perubahan pada remote commit history dan remote repository.
8. **Branch**: Cabang repository baik local maupun remote.
9. **Merge**: Menggabungkan cabang repository sekarang dengan cabang target. Umumnya cabang sekarang dengan cabang utama/master/main.

### Penjelasan bagian gambar/visual
Gambar pada bagian ini kemungkinan menampilkan diagram alur (flowchart) cara kerja Git, yang memperlihatkan hubungan antara **Local Repository** (di komputer user) dan **Remote Repository** (di server GitHub). Diagram ini biasanya menunjukkan panah-panah dengan label perintah seperti **Add, Commit, Push** (dari Local ke Remote) dan **Pull, Fetch, Merge** (dari Remote ke Local). Visualisasi alur ini sangat penting untuk membantu mahasiswa memahami konsep abstrak dari version control secara visual.
