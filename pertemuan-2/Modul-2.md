## About Unreal Engine

Unreal Engine dikembangkan oleh **Epic Games**, yaitu perusahaan yang juga dikenal sebagai pembuat game **Fortnite**.

Unreal Engine digunakan secara luas di berbagai bidang, seperti:

- Industri film.
- Arsitektur.
- Otomotif.
- Simulasi.
- Pengembangan game.
- Industri lain yang membutuhkan visual berkualitas tinggi dan performa real-time.

Unreal Engine menjadi pilihan utama untuk menghasilkan visual dengan kualitas tinggi serta performa real-time, baik dalam alur kerja yang lincah/agile maupun pipeline produksi yang kompleks dan melibatkan banyak disiplin ilmu.

Melalui Unreal Engine, pengguna memiliki akses ke fitur-fitur kuat yang sama dengan fitur yang digunakan oleh studio game AAA ternama.

Terdapat catatan mengenai lisensi/royalti:

> **A 5% royalty only applies if you release a game commercially and it exceeds $1,000,000 USD in gross revenue.**

Artinya, royalti sebesar 5% hanya berlaku jika pengguna merilis game secara komersial dan game tersebut mendapatkan pendapatan kotor lebih dari **1.000.000 USD**.

Selain itu, slide ini menegaskan:

> **IT’S FREE!***

Artinya Unreal Engine dapat digunakan secara gratis, dengan ketentuan royalti seperti yang telah dijelaskan sebelumnya.

### Penjelasan bagian gambar/visual
Bagian visual pada slide ini biasanya menampilkan logo Unreal Engine, logo Epic Games, atau ilustrasi yang menunjukkan bahwa Unreal Engine digunakan oleh banyak industri. Visual ini menegaskan posisi Unreal Engine sebagai engine yang profesional, gratis untuk digunakan pada tahap awal, dan memiliki standar industri AAA.

## One Engine for All Platform

Unreal Engine memungkinkan pengguna untuk melakukan deploy atau distribusi build ke berbagai platform secara seamless. Platform yang disebutkan meliputi:

- **PC**, yaitu Windows, Mac, dan Linux.
- **Consoles**, yaitu PS5 dan Xbox.
- **Mobile**, yaitu iOS dan Android.

Slide ini juga memberikan contoh penggunaan ekstrem Unreal Engine:

> For extreme use case, Kuro Games effectively deploy a massive open-world game on modified version of Unreal Engine to achieve simultaneous, same-day live updates across PC, console, and low-end mobile devices.

Artinya, dalam kasus penggunaan ekstrem, **Kuro Games** secara efektif menggunakan versi modifikasi Unreal Engine untuk merilis game open-world berskala besar. Dengan pendekatan tersebut, mereka mampu melakukan update live secara serentak pada hari yang sama untuk platform PC, console, dan perangkat mobile dengan spesifikasi rendah.

### Penjelasan bagian gambar/visual
Bagian gambar pada slide ini kemungkinan menampilkan ilustrasi berbagai platform, seperti PC, console, dan mobile, atau menampilkan visual game dari Kuro Games. Dalam referensi disebutkan cover **Wuthering Waves**, sehingga gambar dapat berkaitan dengan game buatan Kuro Games. Gambar ini berfungsi menunjukkan bahwa Unreal Engine dapat digunakan untuk proyek lintas platform, termasuk proyek besar dengan kebutuhan update serentak di banyak perangkat.

## Fungsi Top Bar

Slide ini menjelaskan fungsi-fungsi yang ada pada **Top Bar** atau toolbar bagian atas Unreal Editor.

Fungsi-fungsi yang disebutkan meliputi:

1. **Save Changes on Current Level**  
   Digunakan untuk menyimpan perubahan pada level yang sedang dibuka.

2. **Switches editor workflow modes**  
   Digunakan untuk berpindah mode kerja editor. Mode yang disebutkan meliputi:
   - Landscape
   - Foliage
   - Mesh Paint
   - Modeling
   - Animation editing

3. **Add Objects**  
   Digunakan untuk menambahkan objek ke dalam level.

4. **Blueprints Menu**  
   Digunakan untuk mengakses fitur Blueprint, yaitu sistem visual scripting di Unreal Engine.

5. **Cinematics/Sequencer**  
   Digunakan untuk mengakses fitur sinematik atau Sequencer.

6. **PLAY**  
   Digunakan untuk menjalankan game atau simulasi dari level yang sedang dibuat.

### Penjelasan bagian gambar/visual
Gambar pada bagian ini menampilkan toolbar atas pada Unreal Editor. Toolbar ini berisi tombol-tombol penting seperti save, mode kerja, add actor/objek, Blueprint, Sequencer, dan tombol Play. Visual ini membantu pengguna mengenali letak tombol-tombol utama yang akan digunakan selama praktikum.

## PLAY, STOP, dan Keluar Viewport

Slide ini menjelaskan penggunaan tombol Play dan kontrol saat menjalankan game.

Instruksi yang diberikan:

- Klik tombol **Play** untuk memulai game.

### Penjelasan bagian gambar/visual

Saat mode Play aktif, pengguna dapat menghentikan permainan dengan tombol Stop atau tombol **Escape**. Kombinasi **SHIFT + F1** digunakan ketika pengguna ingin tetap berada dalam mode Play, tetapi ingin membebaskan kursor mouse agar bisa mengklik bagian editor lain di luar viewport.
